# E2M3, decompiled

`maps/blood/E2M3.MAP` treated as a compiled binary whose source was lost, and
recovered far enough to read and edit as a program.

**Authority.** `E2M3.MAP` is the truth. Everything here is derived, interpreted,
or both, and `provenance.json` says which. The exact `LevelIR` is deliberately
not committed — it is 2.3 MB and reproducible byte-for-byte:

```bash
python -m bloodmap decompile maps/blood/E2M3.MAP -o work/E2M3.level-source.json
```

## What is here

| Path | What it is |
| --- | --- |
| `provenance.json` | CRC, counts, and the commands that regenerate everything |
| `hierarchy.json` | the derived tree as a reading view, without the wall lists |
| `structures.json` | recovered architectural structures with parameters and residuals |
| `assets.json` | this level's dominant tiles, with local role aliases |
| `nodes.jsonl` | one grep-able line per searchable node, structure and relation |
| `references/abstraction-candidates.json` | the corpus evidence for every promotion decision |
| `references/area-proposals.json` | the proposed major areas, every merge with its reasons |
| `references/area-evidence.md` | what the grouping is made of, and what visibility changed |
| `references/names.json` | the interpreted names, with the measurement behind each |
| `source/` | the refactoring history, stage by stage |

## The refactoring history

Each stage is runnable and each is a strictly more useful reading than the last.

```bash
PYTHONPATH=. python projects/e2m3-decompiled/source/stage1_canonical.py
PYTHONPATH=. python projects/e2m3-decompiled/source/stage2_hierarchy.py
PYTHONPATH=. python projects/e2m3-decompiled/source/stage3_structures.py
PYTHONPATH=. python projects/e2m3-decompiled/source/stage4_vocabulary.py
PYTHONPATH=. python projects/e2m3-decompiled/source/E2M3.py
```

**Stage 1 — canonical.** Exact truth, and the honest label for what the old
"readable Python" emitter produces: 138,008 lines, of which 136,616 -- 99% of
the file -- are one embedded `LevelIR` literal. Editing its functions changes
nothing.

**Stage 2 — hierarchy.** The level as twenty places instead of 340 sectors, with
a local name for the eight the measurements actually distinguish and an explicit
refusal to name the other 128.

**Stage 3 — structures.** What the places are built from, with the essential
parameters and the residual kept apart. E2M3 has two stepped runs: one is four
rises of 4096 with treads varying by 111 units, and one is `[4096, 3072, 1024]`,
which no constant-rise constructor should pretend to reproduce.

**Stage 4 — vocabulary.** Stage 3's four numbers spent on new geometry
elsewhere, compiled, and handed back to the same detector. The essential
parameters come back; the tread jitter does not, by design.

**`E2M3.py` — the program.** The whole level as a tree of builders, 6,016
lines, each part owning its own geometry in its own coordinates and its own
sprites. Generated by:

```bash
python -m tools.emit_level_program maps/blood/E2M3.MAP \
    --art-dir reference/blood --names projects/e2m3-decompiled/references/names.json \
    --areas projects/e2m3-decompiled/references/area-proposals.json \
    -o projects/e2m3-decompiled/source/E2M3.py
```

The `--areas` argument is the middle of the tree. Without it `build_main_complex`
is 138 lines calling 123 space builders in one flat list; with it, it is 41
lines calling 25 zone builders, each stating in its docstring what measurement
grouped it. See [area-evidence.md](references/area-evidence.md).

## Reading it

```python
from E2M3 import build_level
program = build_level()
print(program.tree())                       # where am I
room = next(r for r in program.rooms() if r.node_id == "sector_212")
print(room.summary())                       # everything about one part
```

`NATIVE_ESCAPES` at the top of the file lists the sectors the authoring model
cannot express, with the compiler's own reason. They exist in the MAP and are
absent here rather than silently repaired.

The program builds 339 of E2M3's 340 rooms and lowers to 339 `PlanarLayout`
regions and 443 placements. Recompiling it from there stops on two sectors that
traverse one shared edge the same way round — 4 such edges in E2M3, 15 in the
whole corpus. The tree and the lowering are complete; the round trip is not, and
that gap is the measurement rather than a defect to paper over.

## What the names mean

Every name in `references/names.json` cites only measured facts — footprint,
sky, dominant tiles, sprite count, recovered structures, connectivity — and
carries a confidence. `main_open_ground` is high confidence; `sprite_dense_interior`
is low, and says so. Names are interpretation and never evidence.
