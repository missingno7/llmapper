# The module map

Every module in `bloodmap/` and every tool in `tools/`, one line each. Look
here before writing a helper: if it is about a map, somebody has probably
already written it.

Generated by `python -m tools.module_map` from each module's own docstring;
`tests/test_module_map.py` fails when this page is out of date or a module
has not been placed in a layer. Which module owns which *kind of fact* is
[architecture](architecture.md); what to reach for when building is
[the toolkit index](toolkit-index.md).

## The library: `bloodmap/`

### Native formats

Bytes to exact models and back. Nothing here interprets; every writer reconstructs the file from decoded fields.

| Module | What it is |
| --- | --- |
| `format` | Blood v7 MAP bytes: parse and encode, with the encryption, the CRC and the packed extended records. |
| `model` | The exact models: `DiskMap` mirrors the file, `LevelIR` is its editable JSON form. |
| `duke` | Classic Duke Nukem 3D v7 MAP bytes, mirrored exactly as `DukeDiskMap`. |
| `doom` | Classic Doom WAD and map native representation. |
| `art` | Build ART tile archives and palettes: sizes, pixels, appearance features and nearest-tile matching. |
